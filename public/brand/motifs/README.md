# Motifs

15 geometric motifs × 5 logo pairs, generated from `lib/landing/motifs.ts` by
`npm run brand:motifs`. Do not edit these files by hand; change the source and re-run.

File name: `<motif>-<pair>.svg`, 160×90, dark ground. Motifs: em, lightsheet, oct, tracts, surface, matrix, fmri, meg, anat, pipeline, qa, stats, table, zarr, generic.
Pairs: blueteal, redorange, orangeyellow, tealyellow, lightblueorange.
